Codeformer是由新加坡南洋理工大學的學者

所發表的一套針對人臉修復的生成式AI

使用的方式需要先搜尋codeformer這個關鍵字

然後來到Github的頁面

可以看到它支援Google colab

Hugging Face還有Replicate

這三家不同的虛擬主機服務網站

Colab操作比較複雜

不建議選用

Hugging Face我自己測試的時候

一直遇到Error錯誤

我這邊建議選擇Replicate這個

點選圖示進到網站之後

我們可以看到官方的範例圖片

我們直接往下滑

找到左下角的Sign in With Github

這邊需要登入Github的帳號

如果你還沒有Github的帳號

點選Create an account

輸入使用者帳號user name

Email信箱還有password密碼

點選Verify驗證真人

完成登入之後

接著回到剛剛的Replicate頁面

找到左邊的image區域

點選click to select

然後上傳我們模糊版的愛因斯坦圖片

下面的Upscale值建議改到2

剩下的參數都不用動

點選Submit

Boom 完成囉

我們點選右邊的Download按鈕

我們來比較一下

原始圖片跟AI優化過的圖片

可以明顯看出臉部的細節
