patch 就誕生啦

ChatGPT 理解內容的最小單位是 token

token 是類似單詞的文字語意

ChatGPT 用 token 玩文字接龍

產生有連續且有意義的句子和文章

那 Patch 呢

其實就是圖片版的 token

讓 ChatGPT 可以用圖片玩接龍

玩出有連貫性的圖片

Sora 官方提供的訓練說明圖上

最後形成的那些方塊就是 patch

這些 patch 是包含時間在內的4D立體拼圖

可以針對畫面與時間的連續性進行計算

那這個 patch 要怎麼做呢

以 Sora 提供的參考文獻15

來說明會比較容易

patch 是將影像切成一樣等大的區塊後

進行編碼、壓縮產生類似 ChatGPT

能分析的文字語意 token

有了這些 patch 後

Transformer 就可以計算

patch 之間的關聯性 形成序列

例如論文中被分割在中上與右上的兩塊藍天

就會被分類在天空中

之後算圖時

必須要一起動
