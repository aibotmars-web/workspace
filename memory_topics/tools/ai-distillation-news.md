# AI 蒸餾攻擊新聞 (2026-02-24)

## 事件
Anthropic 指控 DeepSeek、Moonshot (Kimi)、MiniMax 透過蒸餾攻擊竊取 Claude 模型能力。

## 攻擊手法
- 建立 2.4 萬個偽造帳號
- 產生 1,600 萬次對話
- 提取思維鏈 (Chain-of-Thought) 訓練資料
- 繞過政治敏感話題審查

## 為何是國安問題
- 蒸餾出的模型移除安全防護
- 可能用於生化武器、網路攻擊
- 去安全化模型危害難以估量

## 產業影響
- 中國 AI 對競爭對手依賴程度比想像深
- MiniMax 在 Anthropic 更新模型後 24hr 內切換流量
- 出口管制可能有效，只是被非法手段掩蓋

## Anthropic 對策
1. 行為指紋偵測
2. 跨產業情報共享
3. 存取路徑強化驗證
4. 模型層反制措施
