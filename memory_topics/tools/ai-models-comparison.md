# AI 模型選擇參考 (2026-02-24)

## 網友分享 - 各模型比較

### 1. Kimi K2.5
- **費用:** ¥31/月 (Allegretto)
- **評價:** 能力不錯，適合一般人
- **穩定度:** 好，沒斷線過
- **缺點:** 需要 Cooldown

### 2. MINIMAX M2.5
- **費用:** $100/年 (國際版)
- **優點:** 指令遵循度最好，不會自作主張
- **缺點:** 陸版設定較麻煩
- **適合:** 開發軟體

### 3. Qwen3.5 Plus
- **費用:** $100/年
- **評價:** 能力最強
- **缺點:** 很像自作主張，設定複雜

### 4. Claude Opus 4.6
- **費用:** 上不封頂
- **缺點:** 會自作主張
