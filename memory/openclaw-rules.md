# 老闆的重要指示

## 系統修改原則（2026-02-22 新增）

### ⚠️ 嚴禁事項
1. **嚴禁擅自修改 OpenClaw 系統**
2. **未來有關 OpenClaw 的所有設定必須查看官方文檔**

### 📋 正確流程
未來有任何 OpenClaw 相關設定需求時：
1. 查閱官方文檔：https://github.com/openclaw/openclaw
2. 找到正確修改方式
3. **必須先告知老闆**（在心安過程修改什麼、為什麼要改）
4. 經老闆同意後才能執行

### 💡 原因
- 避免 LLM 幻覺導致系統當機
- OpenClaw 是複雜的 AI 系統，需要謹慎操作
