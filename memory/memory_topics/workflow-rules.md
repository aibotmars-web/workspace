# 工作流規則 (Workflow Rules)

## 核心原則

### 對話節奏
- 每 10 句話自動濃縮到 memory/YYYY-MM-DD.md
- 超過 3 小時未回答要主動追問
- 避免快速連續多個需求

### 當機處理
- 看到 `tool id not found` 立即建議 `/new`
- 複雜任務分批做
- 長時間對話後主動建議 `/new`

### 記憶保存
- 每 10 句話自動濃縮
- 不需要問，直接寫入 memory/
- 確保當機時只損失少量內容

## 自動化流程

### 早晨報告 (9:00)
- 天氣查詢
- 待辦事項
- 算命/運勢

### 晚間總結 (22:00)
- 進度回報
- 心情教練
- 反思引導

### Cron 任務
- Trader 市場報告
- 知識庫更新（每6小時）
- 系統監控

## 禁止事項

- 不要自動更新系統
- 不要執行外部腳本
- 不要修改系統核心
