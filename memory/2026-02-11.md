## OpenClaw 完全容器化 ✅ 完成

### 背景
- 用戶要求純 Docker 部署（不共享本機目錄）
- 需要將所有資料複製到 Docker volume

### Docker 遷移步驟

#### Step 1: 停止本機 Gateway
```bash
kill -9 <PID>
launchctl stop gui/.../ai.openclaw.gateway
```

#### Step 2: 複製資料到 Docker
```bash
docker cp ~/.openclaw/workspace openclaw-main:/root/.openclaw/
docker cp ~/.openclaw/agents openclaw-main:/root/.openclaw/
docker cp ~/.openclaw/memory openclaw-main:/root/.openclaw/
```

#### Step 3: 修正 docker-compose.yml
- 移除 `--host` 參數（不支援）
- 修正 nvm 路徑
- 直接執行 `node openclaw.mjs gateway`

### 學習與教訓

1. **LaunchAgent 問題**: Mac 的 launchd 會自動重啟本機 Gateway，導致衝突
   - 解決: `launchctl stop gui/.../ai.openclaw.gateway`

2. **OpenClaw Docker 執行方式**:
   - 不能用 `openclaw gateway start`（需要 systemd）
   - 需要直接執行 `node openclaw.mjs gateway`
   - 需要 `source /root/.nvm/nvm.sh` 載入 nvm 環境

3. **Telegram 409 Conflict**:
   - Revoke token 不一定馬上生效
   - 需要等待 Telegram 伺服器清除舊會話（10-60 分鐘）
   - 最快方式是等待，不是瘋狂 Revoke
