## 核心重点

### 1. OpenClaw 可以赚钱！
- 不只是个人助手
- 是可以部署给客户的**专业工具**
- 可以自动化端到端的工作流程

### 2. 最快赚钱方式：Upwork
- 有人在上面发布 $500-$5,000 的 AI 自动化工作
- RPA (机器人流程自动化)
- 接到 job 后用 OpenClaw/Claude Code 完成任务
- 这是一个**lead generation 机器**

### 3. Sub-Agents 力量大
- 最多可以 spawn **8 个 sub-agents**
- 每个 sub-agent 有自己的电脑
- **并行处理**多个任务
- 策略1：把一个任务分给多个 agents
- 策略2：同一个任务跑多个实例

### 4. 设计思维很重要
- 先画**价值 vs 成本**的图
- 从**高价值、低难度**的开始
- 用 Figma 或 Mermaid 画流程图

### 5. 创业机会
- **垂直领域的电脑使用 agent**（制造、房地产、分销）
- Andreessen Horowitz 正在投资这个方向！

## 技术细节

### 部署方式
- 用 Orgo 在虚拟机上安装（1 分钟搞定）
- 或用 Mac Mini、Manus、Kimi

### Sub-Agents vs Tasks vs Skills
- Sub-agents: 独立运行的 agent
- Tasks: 单一任务
- Skills: 轻量级技能

### TikTok Trend Hunter 案例
- 24:54 开始现场构建
- 从想法到原型只需几分钟

## 关键建议

1. **从小开始**：先构建轻量级 MVP skill
2. **测试、debug、迭代**：不要一开始就搞大的
3. **动手做**：不要只看教程，要实际操作
