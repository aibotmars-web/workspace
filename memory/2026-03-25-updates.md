## ⏰ 自動化設定

### GitHub Monitor Cron Job
- **腳本**：`~/.openclaw/scripts/github-openclaw-monitor.sh`
- **時間**：每天 09:00 自動執行
- **功能**：
  - 抓取 GitHub 最新 releases
  - 抓取最近 merged PRs
  - 比對版本，有新版會標註
  - 濃縮摘要並通知 Telegram
- **儲存**：`~/.openclaw/workspace/memory/github-update-YYYY-MM-DD.md`

### 指令
```bash
# 手動執行
~/.openclaw/scripts/github-openclaw-monitor.sh

# 查看今日報告
cat ~/.openclaw/workspace/memory/github-update-2026-03-25.md
```
