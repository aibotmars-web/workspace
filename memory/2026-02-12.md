#### 目前整合障礙
1. **API Key 需求高**：
   - LLM API（MiniMax 2.1 CN）✅ 可用
   - Vectorize API（本地部署 Qwen3-Embedding-0.6B）⏳ 安裝中
   - Rerank API（暫時跳過）

2. **服務依賴複雜**：
   ```
   MongoDB ← Elasticsearch ← Milvus ← Redis
        ↓
     FastAPI (Python)
   ```

3. **當前狀態**：
   - ✅ Docker 配置已完成
   - ⏳ Embedding 伺服器安裝中
   - ✅ LLM 使用 MiniMax 2.1 CN
