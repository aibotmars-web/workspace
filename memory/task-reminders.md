# 任務提醒追蹤

## 最後通知時間（用於控制不重複通知）

| 任務 ID | 任務名稱 | 最後通知時間 | 狀態 |
|---------|----------|--------------|------|
| - | - | - | - |

## 通知計時器規則
```
├─ 發送通知 → 記錄時間到這個檔案
├─ 下次通知前 → 檢查「最後通知時間」
├─ 如果 < 12 小時 → 不發送
├─ 如果 > 12 小時 → 可以再次提醒
└─ 用戶回覆任何訊息 → 重置計時器（刪除該任務的記錄）
```

## 緊急事項（不受 12 小時限制）
- Polymarket 虧損 > 5%
- 系統異常
- 重大截止日期（今天到期）

## 更新方式
每次發送任務提醒時：
1. 讀取這個檔案
2. 檢查該任務是否在列表中
3. 如果 < 12 小時，不發送
4. 如果 > 12 小時，發送後更新時間
