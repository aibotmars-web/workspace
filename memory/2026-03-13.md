# 2026-03-13 日記憶

## 重要修復（Claude Code 協助）
老闆反映 OpenClaw 幾乎每天失憶，診斷出 5 個根本原因：

### 問題
1. 每次只注入 3 條記憶（太少）
2. 日記憶檔 3/9-3/13 全部缺失（ENOENT）
3. Gateway 多次 OOM 崩潰（4GB heap limit）
4. Jina Embedding API 偶發 429 限流
5. jina-embeddings-v2-base-en 是英文模型，中文對話檢索效果差

### 修復
1. Gateway plist 加入 `NODE_OPTIONS --max-old-space-size=6144`（6GB heap）
2. index.ts 記憶注入 limit: 3 → 8
3. openclaw.json 啟用 autoCapture、autoRecall、enableManagementTools
4. retrieval 設定優化：candidatePoolSize=30, minScore=0.2, recencyWeight=0.15
5. sessionMemory 啟用（messageCount=25）
6. 補建 3/9-3/13 日記憶檔

### 待辦
- 考慮將 embedding 模型從 jina-embeddings-v2-base-en 換成支援中文的模型
